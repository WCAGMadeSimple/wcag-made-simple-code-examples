Not all bolds are strong, not all italics are emphasized

Read this page with a screen reader of your choice to hear how these different implementations of bold and italic are announced.

Afterwards, use Firefox to inspect the Accessibility Tree and see the difference in how these implementations are seen by assistive technologies.

Bolds

  • b tag bolded text
  • CSS font-weight bolded text
  • strong tag bolded text

Italics

  • i tag italicized text
  • CSS font-style italicized text
  • em tag emphasized text
